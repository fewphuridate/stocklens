# StockLens — เว็บคัดหุ้นไทยและต่างประเทศ อัปเดตรายวัน

จัดอันดับหุ้นไทย (กลุ่ม SET100) และหุ้นต่างประเทศ (หุ้นใหญ่สหรัฐฯ + ADR) ตามระยะเวลาลงทุน **1 / 3 / 6 / 9 เดือน**
จากปัจจัยพื้นฐาน งบการเงิน มุมมองนักวิเคราะห์ ข่าว และแนวโน้มราคา พร้อมเหตุผลภาษาไทยว่าทำไมน่าสนใจ/ต้องระวัง
และสถิติโอกาสขึ้นจากข้อมูลย้อนหลัง ~10 ปี

> ⚠ เป็นเครื่องมือคัดกรองเชิงสถิติ **ไม่ใช่คำแนะนำการลงทุน** ข้อมูลฟรีอาจล่าช้า/คลาดเคลื่อน ตรวจสอบกับแหล่งทางการก่อนตัดสินใจเสมอ

## เริ่มใช้งาน (Windows)

1. ติดตั้ง Python 3.10 ขึ้นไป แล้วติดตั้งแพ็กเกจ
   ```bash
   python -m pip install -r requirements.txt
   ```
2. ดับเบิลคลิก **`update.bat`** — ดึงข้อมูลครั้งแรก (ประมาณ 3–5 นาที, log อยู่ที่ `logs\update.log`)
3. ดับเบิลคลิก **`serve.bat`** — เปิดเว็บที่ http://localhost:8000

คำสั่งเพิ่มเติม:
```bash
python -m pipeline.build --markets th     # อัปเดตเฉพาะหุ้นไทย
python -m pipeline.build --use-cache      # คำนวณใหม่จากข้อมูลที่ดึงไว้ภายใน 20 ชม. (เร็ว ใช้ตอนปรับน้ำหนัก)
python -m pipeline.build --ai             # สรุปข่าวภาษาไทยด้วย Claude (ดูด้านล่าง)
```

## อัปเดตอัตโนมัติทุกวัน

**แบบที่ 1 — บนเครื่องนี้ (Task Scheduler)** เปิด PowerShell แล้วรัน:
```powershell
$a = New-ScheduledTaskAction -Execute "C:\Few\Claude Web\Stock web\update.bat"
$t = New-ScheduledTaskTrigger -Daily -At 7:00
$s = New-ScheduledTaskSettingsSet -StartWhenAvailable
Register-ScheduledTask -TaskName "StockLens Daily Update" -Action $a -Trigger $t -Settings $s
```
รันทุกวัน 07:00 น. (หลังตลาดสหรัฐฯ ปิด) ถ้าคอมปิดอยู่ จะรันทันทีเมื่อเปิดเครื่อง · ยกเลิกด้วย `Unregister-ScheduledTask -TaskName "StockLens Daily Update"`

**แบบที่ 2 — บนคลาวด์ฟรี (GitHub Actions + GitHub Pages)** เปิดดูได้จากมือถือทุกที่ ไม่ต้องเปิดคอม
1. สร้าง repository ใหม่ที่ https://github.com/new (เช่นชื่อ `stocklens`, แบบ Public, ไม่ต้องติ๊กสร้าง README)
2. ในโฟลเดอร์โปรเจกต์ รัน (แทน `USERNAME` ด้วยชื่อบัญชี GitHub —
   อีเมลแบบ `...@users.noreply.github.com` ช่วยไม่ให้อีเมลจริงถูกเปิดเผยใน repo สาธารณะ ดูได้ที่ GitHub → Settings → Emails)
   ```bash
   git config user.name "USERNAME"
   git config user.email "USERNAME@users.noreply.github.com"
   git commit -m "StockLens: first version"
   git remote add origin https://github.com/USERNAME/stocklens.git
   git push -u origin main
   ```
3. บน GitHub: Settings → Pages → Source เลือก **GitHub Actions**
4. Actions → Daily update → **Run workflow** (ครั้งแรก) รอประมาณ 5 นาที เว็บจะอยู่ที่ `https://USERNAME.github.io/stocklens/`
   (รอบที่รันเองตอน push ครั้งแรกอาจขึ้นสีแดงที่ขั้น deploy เพราะยังไม่ได้เปิด Pages — ไม่เป็นไร กด Run workflow ใหม่หลังทำข้อ 3)
   จากนั้นจะรันเองทุกเช้าวันอังคาร–เสาร์ 06:30 น. และทุกครั้งที่ push โค้ดใหม่

ใน git จะเก็บเฉพาะประวัติที่ต้องสะสม (`web/data/snapshots`, `web/data/history`) ไฟล์ข้อมูลอื่นสร้างใหม่ทุกรอบ repo จึงไม่โตเร็ว

หมายเหตุ: GitHub Pages ของ repo แบบ private ต้องใช้แพ็กเกจเสียเงิน ถ้าใช้ repo แบบ public เว็บจะเปิดให้ทุกคนเห็น (รายการติดตามเก็บในเบราว์เซอร์ของแต่ละคน ไม่ถูกเผยแพร่)
บางครั้ง Yahoo Finance อาจจำกัดการดึงข้อมูลจากเซิร์ฟเวอร์คลาวด์ ถ้ารันไม่ผ่านให้กดรันซ้ำ

## สรุปข่าวด้วย AI (ไม่บังคับ มีค่าใช้จ่าย)

```bash
python -m pip install anthropic
set ANTHROPIC_API_KEY=sk-ant-...
python -m pipeline.build --ai
```
วิเคราะห์ข่าวของหุ้น 15 อันดับแรกต่อตลาด (แก้จำนวนได้ที่ `AI_TOP_N_PER_MARKET` ใน `pipeline/config.py`)
ใช้โมเดล `claude-opus-5` เป็นค่าเริ่มต้น เปลี่ยนได้ด้วยตัวแปร `STOCKLENS_AI_MODEL` (เช่น `claude-sonnet-5` หรือ `claude-haiku-4-5` ถ้าต้องการประหยัด)
ผลสรุปแสดงในหน้ารายละเอียดหุ้นเท่านั้น ไม่นำไปคำนวณคะแนน

## ปรับแต่ง

| ต้องการ | แก้ที่ |
|---|---|
| เพิ่ม/ลบหุ้นที่ติดตาม | `pipeline/universe.py` |
| น้ำหนักปัจจัยแต่ละระยะเวลา, เกณฑ์ป้าย "เด่นมาก/น่าสนใจ/…" | `pipeline/config.py` (`WEIGHTS`, `LABELS`) |
| ตัวชี้วัดในแต่ละกลุ่มปัจจัย | `pipeline/scoring.py` (`METRICS`) |
| ข้อความเหตุผลภาษาไทย | `pipeline/reasons.py` |
| คำที่ใช้วัดโทนข่าว | `pipeline/news.py` |

## วิธีคิดคะแนน (ย่อ)

- **7 กลุ่มปัจจัย:** มูลค่า, คุณภาพกิจการ (รวม Piotroski F-Score), การเติบโต, แนวโน้มราคา, มุมมองนักวิเคราะห์, ข่าว, ความเสี่ยงต่ำ
  ทุกตัวชี้วัดแปลงเป็นเปอร์เซ็นไทล์เทียบกับหุ้นในตลาดเดียวกัน (มูลค่า/คุณภาพเทียบกับกลุ่มอุตสาหกรรมด้วย)
- **คะแนนแนะนำ** = ผลรวมถ่วงน้ำหนัก ระยะสั้นเน้นแนวโน้มราคาและข่าว ระยะยาวเน้นมูลค่า คุณภาพ การเติบโต
- **โอกาสขึ้น** = สถิติ 10 ปีของหุ้นทุกตัวในตลาดเดียวกันที่อยู่ใน "สภาวะราคา" เดียวกับวันนี้ (เหนือ/ใต้ MA200 × โมเมนตัม 3 เดือน)

### ผลทดสอบย้อนหลังที่ควรรู้
- ตัวเลข "โอกาสขึ้น" ตรงกับความจริงในภาพรวม (คลาดเฉลี่ย ~3–6%) แต่ **แยกหุ้นที่จะขึ้น/ไม่ขึ้นได้น้อยมาก**
  สถิติรายหุ้นยิ่งแย่กว่า จึงแสดงเป็นข้อมูลประกอบ ไม่รวมในคะแนน
- ปัจจัย **แนวโน้มราคา (โมเมนตัม) ใช้ได้จริงในหุ้นไทย** ช่วง 2017–2026 แต่ไม่ชัดในหุ้นสหรัฐฯ
- หุ้นผันผวนต่ำไม่ได้ให้ผลตอบแทนดีกว่า จึงให้น้ำหนักกลุ่ม "ความเสี่ยงต่ำ" ไว้เพื่อคุมความเสี่ยงเท่านั้น
- ปัจจัยพื้นฐานย้อนหลังแบบ ณ วันนั้นไม่มีให้ใช้ฟรี จึงทดสอบย้อนหลังไม่ได้ — ระบบจึง **บันทึกหุ้น 10 อันดับแรกทุกวัน**
  แล้ววัดผลจริงเทียบดัชนีในหน้า "ผลงานย้อนหลัง" ยิ่งรันนานยิ่งรู้ว่าคะแนนใช้ได้แค่ไหน

## โครงสร้างโปรเจกต์

```
pipeline/            ดึงข้อมูลและคำนวณ (Python)
  universe.py        รายชื่อหุ้น
  config.py          น้ำหนักและค่าตั้งต้น
  fetch.py           Yahoo Finance + Google News RSS
  technicals.py      ผลตอบแทน, MA, RSI, ความผันผวน
  fundamentals.py    อัตราส่วน, งบการเงิน, F-Score
  news.py            โทนข่าวไทย/อังกฤษ
  probability.py     สถิติโอกาสขึ้น + ทดสอบย้อนหลัง
  scoring.py         คะแนนกลุ่มปัจจัยและคะแนนแนะนำ
  reasons.py         เหตุผลภาษาไทย
  track.py           บันทึกหุ้นที่แนะนำ/ประวัติคะแนน/ผลงานจริง
  ai_news.py         สรุปข่าวด้วย Claude (ไม่บังคับ)
  build.py           จุดเริ่มรัน
web/                 หน้าเว็บ (HTML/CSS/JS ไม่ต้อง build)
  data/              ไฟล์ JSON ที่ pipeline สร้าง
update.bat           อัปเดตข้อมูล
serve.bat            เปิดเว็บบนเครื่อง
```

แหล่งข้อมูล: Yahoo Finance (ผ่าน `yfinance`) และ Google News RSS — ใช้เพื่อการศึกษาส่วนตัว โปรดเคารพเงื่อนไขการใช้งานของแหล่งข้อมูล
